# Decorati Perú - Sitio Web Oficial & Documentación Técnica

Repositorio del código fuente de la página web oficial de **Decorati Perú** (`https://decoratiperu.com/`). 

Este proyecto ha sido desarrollado y optimizado a nivel de estructura HTML5 semántica, rendimiento de carga, accesibilidad y **SEO On-Page** para maximizar el posicionamiento en motores de búsqueda (Google) en categorías como **cuadros personalizados**, **cuadros MDF** e **iluminación LED**.

---

## Tecnologías y Recursos

* **HTML5:** Estructura semántica avanzada optimizada para motores de búsqueda.
* **Tailwind CSS (CDN):** Framework de diseño responsivo, estético y ágil.
* **Lucide Icons:** Biblioteca de iconos vectoriales ligeros (SVG).
* **Google Fonts:** Tipografías web *Plus Jakarta Sans* (cuerpo) y *Playfair Display* (títulos de marca).

---

## Optimización SEO e Identidad Visual Aplicada

Se realizaron las siguientes optimizaciones técnicas directas en el encabezado (`<head>`) del sitio:

1. **Jerarquía de Títulos (`<title>`):**
   * Se antepuso la palabra clave de mayor intención comercial e interés local (*"Cuadros Personalizados en Perú"*) para captar tráfico con intención transaccional en Google.
2. **Estandarización de Favicon (Google Crawler Spec):**
   * Se configuró el icono principal en formato **PNG (`192x192 px`)** para cumplir con los estándares directos del bot de Google (*Google Favicon Crawler*), garantizando que el logo oficial reemplace al icono genérico del buscador en móviles y PC.
3. **Meta Descripciones y Open Graph:**
   * Textos optimizados para aumentar la tasa de clics (CTR) en los resultados de búsqueda y vista previa profesional en tarjetas de **WhatsApp, Facebook e Instagram**.

---

## Sistema de Diseño y Estilos

El proyecto utiliza una configuración adaptada para reflejar la identidad visual de la marca:

* **Tipografías:**
  * **Títulos (`h1`, `h2`, `h3`):** `'Playfair Display', serif` (aporta elegancia y acabado de galería).
  * **Texto general y botones:** `'Plus Jakarta Sans', sans-serif` (alta legibilidad en móviles).
* **Paleta de Colores Principal:**
  * **Fondo / Dark Mode Accent:** `#0F172A` (Slate 900)
  * **Texto Principal:** `#F8FAFC` (Slate 50)
  * **Acentuaciones / CTA:** Colores cálidos y dorados para resaltar botones de conversión a WhatsApp.
